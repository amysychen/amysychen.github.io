# Amy Chen — Personal Portfolio

A single-page portfolio inspired by [Brittany Chiang](https://brittanychiang.com/)’s clean, dark theme and section-based layout.

## Run locally

Open `index.html` in a browser, or use a simple server:

```bash
# Python 3
python3 -m http.server 8000

# Node (npx)
npx serve
```

Then visit **http://localhost:8000**.

## Contents

- **Hero** — Name, tagline, and short intro
- **About** — Bio and highlights
- **Experience** — Roles at BGC Group, Houlihan Lokey, New Song Studio, Hunter College
- **Skills** — Core skills and education
- **Contact** — Email, phone, resume link

Resume PDF (`Amy Chen_2025Dec.pdf`) is in the project root; the “Resume” buttons link to it.

## Customize

- **styles.css** — Colors (CSS variables at the top), typography, layout
- **index.html** — Copy, links, and section content
